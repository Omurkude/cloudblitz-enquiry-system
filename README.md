# CloudBlitz Enquiry Management System

A full-stack Enquiry Management System built using React, Node.js, Express and MongoDB.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express
- JavaScript
- MongoDB
- Mongoose

## Project Structure

- `frontend` - React frontend
- `backend` - Express backend
- `docs` - Project documentation
